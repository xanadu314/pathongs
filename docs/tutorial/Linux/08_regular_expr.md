```{bash}
cat mm10.txt |grep -v "#"| awk '$6 ~ /^chr[0-9][0-9]*$/ || $6 ~ /^chr[X|Y|M]$/' | awk  -F"\t" -v OFS="\t" '{print $6,$7,$8,$13,".",$10}' | sed 's/^chr//' > repeat.bed
```

~代表正则匹配

^chr以chr开头

```{bash}
[0-9][0-9]*代表任意个数的[0-9]
||代表或者
可以将～改为！～代表不符合
```
