# Canu组装三代测序数据

Canu由 [Celera Assembler](http://wgs-assembler.sourceforge.net/)研发，目前已经不在维护，专门用来组装Pacbio和Nanoproe的测序数据。

**Canu1.X和2.X的版本参数设置差异较大，注意区分**

## Canu Pipline

![canupipline](https://canu.readthedocs.io/en/latest/_images/canu-pipeline.svg)



## Canu组装Pacbio CLR或Nanoproe的测序数据

只需要一个输入文件，需要指定文件前缀，输出文件夹和预估的基因组大小。

```bash
canu -p test -d test genomeSize=40m -pacbio pacbio.fastq
```

## Canu组装Pacbio HiFi测序数据

```bash
canu -p test -d test genomeSize=40m -pacbio-hifi pacbio_hifi.fastq
```

## Canu 手动模式

很多时候需要手动调节Canu的参数，主要包括：

- Correct 校正
- Trim 修剪
- Assemble 组装

首先是Correct raw data

```bash
canu -correct -p test -d test genomeSize=400m -corrected -pacbio pacbio.fastq
```

会生成Correct后的test.correctedReads.fasta.gz文件。

接下来是Trim corrected reads

```bash
canu -trim -p test -d test02 genomeSize=40m -corrected -pacbio test.correctedReads.fasta.gz
```

会生成Trim后的trimmedReads.fasta.gz文件

最后是组装

```bash
canu -p test -d test03 genomeSize=40m correctedErrorRate=0.039 -trimmed -corrected -pacbio trimmedReads.fasta.gz
```

canu 会自动识别线程

更多参数请参考：
